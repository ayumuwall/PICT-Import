A LITTLE ABOUT PICT

同じPICTでも、
中身はひとつじゃない。

PICT→▧◇Aa

画像も、図形も、文字も。

あるPICTは開くのに、別のPICTは開かない。そんな違いには、ファイルの中に何が記録されているかが関係しています。

PICTは、画像データに加え、線や図形・文字を描くQuickDrawの命令も記録できる形式です。Adobeは、PhotoshopではラスターPICTを開ける一方、QuickDraw PICTの読み込みには対応していないと案内しています。

PICT Importは、画像に加えて基本的な図形や文字の描画命令も処理します。標準の読み込みで開けないPICTを試したいときにお使いください。

macOSの警告でインストーラーが開けません。

「開発元を確認できない」などの警告が出る場合があります。このサイトのリンク先のGitHubリリースから取得したファイルであることを確認したうえで、次の手順で許可してください。

  1. 一度インストーラーを開き、警告が出たら閉じます。
  2. 「システム設定 → プライバシーとセキュリティ」を開きます。macOS 12では「システム環境設定 → セキュリティとプライバシー → 一般」です。
  3. 対象のインストーラーに対して「このまま開く」を選び、案内に従います。

詳しくはAppleの案内をご覧ください。管理されているMacで許可できない場合は、管理者へご相談ください。

すべてのPICTを開けますか？

PICT 1／2の白黒・パレットカラー・RGB画像や、基本的な図形に対応しています。QuickTime形式でJPEGを埋め込んだPICTにも対応しています（分割画像・平行移動・拡大縮小）。他のQuickTime圧縮方式やマット・マスク、一部の特殊な描画は未対応です。MacBinary・AppleDouble・StuffItやリソースフォーク全体からは、先にPICTデータを取り出す必要があります。

詳しい制限はREADMEで確認できます。

昔の図形や日本語の文字は再現できますか？

基本的な図形とMacRomanの欧文文字に対応しています。日本語などは正しく再現できず、欧文も現在のフォントを使うため字形や字幅が変わる場合があります。図形や文字は画像として読み込まれます。

Photoshopにプラグインが表示されません。

Photoshopを終了して起動し直し、「Photoshop → プラグインについて」に「Macintosh PICT」があるか確認してください。Photoshop 2025（26.0）以降が必要です。

以前に手動で配置したコピーがある場合は、同じプラグインの二重配置も確認してください。

ZIPでの導入や、アンインストールの方法は？

Photoshopを終了し、プラグインを次の共有フォルダーへ配置します。削除するときは、この中のPICT Import.pluginをゴミ箱へ移動してください。

/Library/Application Support/Adobe/Plug-Ins/CC/

手動導入の詳しい手順はREADMEにまとめています。

不具合を報告したいです。

GitHub Issuesへ、macOS・Photoshop・PICT Importのバージョン、Macの種類（Intel／Apple Silicon）、表示されたエラーを添えてお知らせください。共有可能なサンプルがあると調査に役立ちます。
